CREATEBYMOH Cinematic Studio Theme
================================================================================
An ultra-premium, responsive, hybrid WordPress block theme optimized for luxury 
perfume, streetwear, accessory, and jewelry brands.

Designed for high-converting social motion campaigns, lookbooks, and custom briefs.

--------------------------------------------------------------------------------
1. FEATURES
--------------------------------------------------------------------------------
* Pure Full Site Editing (FSE) & Site Editor Compatible: Zero raw HTML code boxes,
  fully visual drag-and-drop customization in Gutenberg (Appearance -> Editor).
* Hybrid Classic PHP Fallbacks: Seamless classic PHP fallback templates for
  pages, homepages, single posts, and archives.
* WooCommerce Compatible: universal WooCommerce support, including custom templates
  and standard shop pages out of the box.
* Premium Color Palette: Detailed white-to-obsidian gradient block transitioning 
  into cobalt blue (#2643FF) accents.
* Pulsing WhatsApp Floating Widget: Bottom right float linked to +2348164802777 with
  templated creative requests.
* Intercepting Brief Request Form: Custom brief builder that launches default email
  drafts directly to webwizardmarketingagency@gmail.com.
* Full-Featured UGC Pop-Up Player: Native 9:16 vertical looping video modal with
  interactive likes, timelines, and captions.

--------------------------------------------------------------------------------
2. INSTALLATION
--------------------------------------------------------------------------------
1. Log in to your WordPress Admin Dashboard.
2. Navigate to Appearance -> Themes.
3. Click "Add New Theme" -> "Upload Theme".
4. Choose the `createbymoh-theme.zip` file and click "Install Now".
5. Click "Activate" once the installation completes.

--------------------------------------------------------------------------------
3. MENU SETUP
--------------------------------------------------------------------------------
* Go to Appearance -> Menus or customize directly via the Site Editor (Appearance -> Editor).
* Define the primary navigation links mapping to Perfumes, Streetwear, and Jewelry.

--------------------------------------------------------------------------------
4. VIDEO ASSET BUNDLING
--------------------------------------------------------------------------------
High-definition .mp4 campaign video clips are referenced relative to your theme folder:
* Perfume Division Videos:   wp-content/themes/createbymoh-theme/assets/videos/perfume/
* Streetwear Division Videos: wp-content/themes/createbymoh-theme/assets/videos/streetwear/
* Jewelry Division Videos:    wp-content/themes/createbymoh-theme/assets/videos/jewelry/

Please make sure to place your specific cinematic ad assets in these folders inside 
the active theme directory.
